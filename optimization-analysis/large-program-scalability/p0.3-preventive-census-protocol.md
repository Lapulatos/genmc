# P0.3 preventive-order opportunity census

## Decision

Measure before pruning. The first implementation is instrumentation only and is limited
to the exact bundled recursive PSO model. It does not use `SCChecker` or `TSOChecker` as
the CAT consistency result.

## Evidence translated into GenMC terms

The OOPSLA 2022 solver proves two sufficient SC inconsistency patterns for a proposed
`rf(w,r)`: an existing order `r ->* w`, or an enabled same-location write `w'` with
`w ->* w' ->* r`. FM 2026 restores total write serialization and generalizes these to
Self-Reversal, Stale-Read, RMW-Broadcast, and RF-Join over atomic-block quotient order.

GenMC differs in three relevant ways:

1. `co` is already an explicit strict total per-location order, so the old weak-SC
   omission must not be copied.
2. The recursive PSO CAT model defines a monotone direct `order` and positive recursive
   transitive `reach`; therefore adding a direct edge `(u,v)` is certainly inconsistent
   when the pre-choice fixed point already contains `(v,u)`.
3. GenMC exposes split read/write RMW pairs but not the paper's general atomic-block
   quotient. The census may classify RMW cases it can prove from `rmw`; it must not
   synthesize a generic atomic block.

## Counterfactual measurement

For each CAT-rejected candidate label under `--cat-stats`:

1. Materialize the exact full candidate with `GraphAdapter` and evaluate it offline.
2. Construct the pre-choice counterfactual without modifying the execution graph:
   - read candidate: remove its single incoming `rf` edge;
   - write candidate: remove every incident `co` edge for that write;
   - recompute `fr = rf^-1 ; co` exactly.
3. Re-evaluate the same normalized CAAT model. If this counterfactual is inconsistent,
   classify the sample as non-attributable and do not claim a preventive opportunity.
4. Compute `delta = full.order \\ counterfactual.order`. Count a direct-reversal
   opportunity when some `(u,v)` in `delta` has `(v,u)` in counterfactual `reach`.
5. Classify the new direct edge by its primitive origin (`rf/rfe`, `fr`, or `co`) and
   whether an exposed RMW endpoint participates.

This rule is sufficient but intentionally incomplete. It does not assume that absence
of a match means the candidate is consistent.

## Where time and space could fall after a successful census

| Step | Time reduction | Space reduction | Added cost |
|---|---|---|---|
| `getCoherentStores()` | omit a proved-fragile source before `setRf()` and CAT synchronization | no workqueue node for that source | reachability lookup per candidate |
| RF alternative queueing | avoid later prefix replay, graph synchronization, and fixed-point work | fewer `ReadForwardRevisit` objects and retained prefixes | compact per-prefix forbidden-source set |
| `getCoherentPlacings()` / `calcCoOrderings()` | omit a proved-fragile placement before evaluator work | fewer `WriteForwardRevisit` objects | evaluate only incident co/fr delta endpoints |
| CAAT state | fewer rejected transitions and rollback/rebuild operations | lower undo/history high-water mark | sparse reachability index or row bitsets |

The measurement build itself is expected to be slow: it performs two additional offline
fixed-point evaluations for each rejected candidate. Its runtime is not a retention
metric.

## Correctness gates

- Exact model fingerprint; generic edited CAT models remain unchanged.
- Measurement only: returned verdict and candidate lists are byte-for-byte unchanged.
- Counterfactual base must validate relation universes and exact `fr` recomputation.
- Full offline replay must agree that every sampled production rejection is rejected.
- Unit/property suite, mutation oracle, and broad differential run must show zero result
  mismatch and zero safe execution-count mismatch.

## Performance gate for a later pruning prototype

- At least 10% of rejected generic candidates match direct reversal on the formal
  sample, including nontrivial hits in the PSO TIMEOUT/OOM cohort.
- Estimated avoided synchronization plus CAAT operations is at least twice the measured
  lookup work.
- The pruning prototype must reduce aggregate paired CPU with a 95% bootstrap interval
  entirely below 1.0 and must not increase aggregate RSS or OOM count.
